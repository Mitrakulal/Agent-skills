# college-report-builder

A general-purpose skill for building college reports — assignment reports, lab
experiment reports, written assignments, literature reviews and project
reports — in a plain professional standard, verified page by page before
delivery.

It covers the full build: the go-ahead gate, the structure of each report
type, front-page handling (template swap, name/USN rules), the plain
professional standard, verifying numbers against programs actually run,
real-looking terminal screenshots, figures and tables, the build chain, the
page-by-page verification pass, and delivery.

It contains no personal details — every name, USN, course code, faculty name
and institution is a placeholder supplied per document.

Use alongside `college_report_pagination`, which holds the detailed
pagination rules.
