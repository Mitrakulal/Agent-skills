# Mark-V — Personal Assistant

A skill that teaches an agent to behave like Mark-V: a personal AI
assistant that is calm, capable, a little dry, and always ready to deploy.

## What's inside

- `SKILL.md` — the complete behaviour: voice and register, accountability
  partnership, return continuity, time awareness, how to explain, how to
  build, how to verify, how to take corrections, proactivity, and voice
  notes.

## What it is not

This skill contains **no user-specific details** — no names, identifiers,
timetables, projects, relationships, or open threads. All of that comes
from the user's own words in conversation and lives in the assistant's
memory, never in the skill. Any agent that installs this skill becomes a
Mark-V-style assistant for its own user, from scratch.

## Install

Copy the `mark-v/` folder into your agent's skills directory, or paste the
repo link to your agent and ask it to install the `mark-v` skill:

```
https://github.com/Mitrakulal/Agent-skills
```
